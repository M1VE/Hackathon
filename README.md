# Документация по развертыванию и администрированию проекта

Настоящий документ содержит техническое руководство по настройке изолированного виртуального окружения, установке программных зависимостей, инициализации реляционной базы данных и запуску веб-сервера разработки на базе фреймворка Django.

---

## 1. Порядок развертывания компонента

### 1.1. Подготовка изолированного окружения
Для исключения конфликтов системных пакетов инициализируйте и активируйте виртуальное окружение venv:

# Инициализация виртуального окружения
python -m venv venv

# Активация среды выполнения (Платформа: Windows)
venv\Scripts\activate

# Активация среды выполнения (Платформы: macOS / Linux)
source venv/bin/activate

### 1.2. Установка зависимостей
Установите внешние модули и библиотеки, зафиксированные в спецификации requirements.txt:

pip install -r requirements.txt

### 1.3. Миграция схемы базы данных
Выполните генерацию файлов миграций на основе моделей данных и примените их для формирования структуры таблиц в СУБД:

# Анализ изменений моделей и генерация миграций
python manage.py makemigrations

# Синхронизация структуры таблиц с базой данных
python manage.py migrate

### 1.4. Инициализация сервера веб-приложения
Запустите локальный сервер для проверки работоспособности и тестирования системы:

python manage.py runserver

Точка доступа к локальному интерфейсу приложения: http://127.0.0.1:8000/

## 2. Разграничение прав доступа и учетные записи

Для проверки ролевой модели доступа в системе развернуты тестовые учетные записи со следующими конфигурациями прав:

| Уровень доступа (Роль) | Идентификатор (Email / Логин) | Аутентификационный токен (Пароль) |
| :--- | :--- | :--- |
| Администратор системы | admin@demo.local | admin1234 |
| Организатор | organizer@demo.local | demo1234 |
| Ментор | mentor@demo.local | demo1234 |
| Участник | participant@demo.local | demo1234 |

Примечание: Для второстепенных и автоматически сгенерированных профилей пользователей, присутствующих в системе, по умолчанию назначен единый пароль: 6700067z.

### Инициализация дополнительного администратора
При необходимости создания новой учетной записи с правами Superuser (Суперпользователь) выполните следующую команду в терминале и введите требуемые параметры:

python manage.py createsuperuser

---

## 3. Спецификация и инспекция базы данных

По умолчанию в качестве локального хранилища данных используется реляционная СУБД SQLite (файл данных: db.sqlite3).

* Инспекция данных: Для прямого низкоуровневого анализа таблиц, связей и выполнения SQL-запросов непосредственно из среды разработки рекомендуется использовать специализированное программное расширение SQLite Viewer.
* Использование данного расширения позволяет осуществлять оперативный мониторинг состояния сущностей БД без развертывания внешних ресурсоемких систем управления базами данных.
